## How to review

Evaluate each section against this rubric, in this order:

1. HEADLINE - It should be a searchable formula, not a job title: role + core tools/skills + differentiator + location or remote signal (example shape: "Senior Data Engineer | Python, SQL, AWS | AI Pipelines | Remote LATAM"). Recruiters search keywords; the headline is the highest-weight field.

2. ABOUT - The first 2 lines must hook (everything below is hidden behind "see more"). Concrete scope and outcomes, with numbers. No buzzword soup ("passionate", "results-driven"). End with what I'm looking for. Every claim must be backed elsewhere in the profile (don't let me claim fluency my Languages section contradicts).

3. EXPERIENCE - Titles should match what recruiters actually type into search filters (title filters only match the position-title field). Suggest aligned, defensible titles; adding scope in parentheses is fine, like "Analyst (Data Engineering)". Warn me against retitles a background check would contradict, especially on older roles. Employment type (full-time vs contract) must be accurate. Each role needs 2-4 bullets with real numbers (metrics, scale, impact): flag any bullet without one and ask me for the number instead of inventing it. Tell me to strip internal/confidential system or people names while keeping the metrics.

4. SKILLS - Only pin or feature skills I could defend in a live interview. Lead with disciplines (like "Data Engineering") over tools. The top 3 pinned matter most. 15-25 relevant skills beat 50 noisy ones. Flag anything that looks like keyword stuffing.

5. PROJECTS & FEATURED - Recent, real, defensible. Public repos or demos should be linked. Junior-era artifacts that undercut my seniority should go. No self-deprecating copy. Dates must be accurate.

6. OPEN TO WORK - If I'm job searching: is it enabled (a recruiter-only mode exists)? Are all job-title slots filled with titles that exist in LinkedIn's own taxonomy? Employment types, locations + remote, and start date set?

7. CONSISTENCY - My headline, titles, and dates should match my resume, personal site, and GitHub. Flag mismatches I should fix everywhere at once.

8. BILINGUAL PROFILES (if relevant) - LinkedIn supports per-language profile versions: headline, About, and experience descriptions are per-language; skills, education, languages, and featured are shared. If I work in a non-English market but want international reach, recommend an English primary + local-language secondary, and review both.

## Output format

1. SCORECARD - one line per rubric section: solid / needs work / missing, with a one-clause reason.
2. TOP 5 FIXES - ordered by impact, each with a concrete before → after rewrite I can paste.
3. HEADLINE & ABOUT REWRITES - 2 headline options and 1 full About proposal.
4. QUESTIONS FOR ME - missing metrics, target roles, target market. Ask, don't invent.

Be direct, don't flatter. If a section is fine, say so in one line and move on.
